## Electric Vehicle Data Analysis Dashboard

This repository contains a Power BI dashboard that visualizes insights from the Electric Vehicle Population Dataset.  
The dashboard provides a comprehensive overview of electric vehicle adoption, efficiency, and distribution.

## Key Performance Indicators (KPIs)
- Total Vehicles: 150K  
  Understand the overall landscape of electric vehicles, encompassing both BEVs and PHEVs.  
- Average Electric Range: 67.83 km  
  Gauge technological advancements and efficiency of EVs.  
- BEV Vehicles: 117K (78%)  
  Analyze the dominance of fully electric models.  
- PHEV Vehicles: 34K (22%)  
  Assess the market share of plug-in hybrid models.  

## Visualizations
- Total Vehicle by Model Year: Line chart showing growth trends from 2010–2020.  
- Total Vehicle by State: Map visualization highlighting distribution across the U.S.  
- Total Vehicle by Make: Bar chart showing manufacturers like Tesla, Nissan, Chevrolet, Ford, BMW, Kia, Toyota, and more.  
- CAFV Eligibility: Donut chart showing eligibility categories.  
- Total Vehicle by Model: Treemap highlighting popular EV models (Model Y, Model 3, Leaf, Bolt EV, etc.).  

## Theme
- Dark green dashboard theme for clarity and emphasis.  
- KPI cards at the top for quick insights.  
- Interactive filters for City, Electric Utility, and Electric Vehicle Type.

## How to Use
1. Clone this repository.  
2. Open the `.pbix` file in Power BI Desktop.  
3. Explore the dashboard with interactive filters and visuals.  

## Tools Used
- Power BI Desktop* 
- Power Query Editor for data cleaning and transformation  
- DAX Measures for KPI calculations  

## Purpose
This dashboard helps stakeholders, policymakers, and researchers understand the adoption and efficiency of electric vehicles, supporting data-driven decisions for sustainable transportation.
